iMessage MCP

iMessage for AI tools, without Full Disk Access

iMessage MCP is a free, open-source macOS app and MCP server. It lets Claude Code, Codex or any MCP client read, search and send your Messages while your data stays on your Mac. You choose the folder, the limits and every approval.

Install in two minutesView on GitHub

Your data stays safe

No Full Disk Access

You pick the Messages folder in a normal macOS panel. The app gets a read-only, app-scoped bookmark and nothing else.

No network

The app runs in the macOS sandbox without a network entitlement.

You approve every connection

Pick selected chats or all chats, set a time limit and message limits. Stop with one click.

Sending always asks

The exact recipient and full text are shown. Nothing is sent until you press Send.

How it works

  1. Allow the Messages folder. One click, read-only.
  2. Start the AI bridge. You set the duration and the limits. A battery shows the time left.
  3. Connect your AI tool. The app asks you to approve the connection. Stop any time.

Install

You need macOS 13 or later and Xcode command line tools. A free Apple Development certificate is enough.

1. Build and install the app

git clone https://github.com/0xroots/imessage-mcp
cd imessage-mcp
export MSGLOCAL_SIGN_IDENTITY="Apple Development: Your Name (XXXXXXXXXX)"
export MSGLOCAL_TEAM_ID="YOURTEAMID"
./scripts/install.sh

2. Connect your AI tool

Claude Code plugin

/plugin marketplace add 0xroots/imessage-mcp
/plugin install imessage-mcp@imessage-mcp

Codex

codex mcp add imessage-mcp -- /Applications/iMessageMCP.app/Contents/Helpers/messages-mcp \
  "$HOME/Library/Containers/org.messageslocal.app/Data/tmp/messages-mcp.sock"

Any MCP client: add a stdio server with that command and socket path. See the setup guide.

Questions

Does iMessage MCP need Full Disk Access?

No. You pick your Messages folder once in a standard macOS file panel. The app keeps a read-only, app-scoped bookmark to that folder inside the App Sandbox. This was verified on macOS 27.0.1 with real messages.

Is my data sent anywhere?

The app has no network entitlement. Message text leaves your Mac only if the AI tool you connect sends it elsewhere, which is why every connection needs your approval and runs under limits you set.

Can an AI tool send messages without asking me?

No. Each message shows its exact recipient and full text in a confirmation window and is sent only after you press Send this message. A sent message cannot be recalled, and the app cannot confirm delivery.

Which AI tools work with it?

Any client that supports stdio MCP servers, including Claude Code and Codex. Claude Code can install it as a plugin.

What are the known limits?

Some archived message bodies cannot be decoded yet and are marked unsupported. The request-ID journal holds 1,000 entries. Other processes running as you can start the adapter, so approve only requests you started. See the security notes.
